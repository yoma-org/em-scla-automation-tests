# Smoke Suite

[← Test case index](../README.md)

Generated by `npm run cases:build` from the feature files; do not edit it by hand.

**1 test cases.** Run on every deployment, before any other suite. The smoke suite answers one question: *can users still sign in and complete the core business flow?* Every case is P1, Active and automatable, with a happy path. Stages are a reading order, not a run order: each automated case creates its own data so the cases run independently and in parallel.

**Exit rule:** any failure stops the pipeline. Fix it, or roll back the build, before running E2E or regression.

Data-driven cases (with variants) run **only the base row** in smoke. The full variant set runs in regression.
